一 安装依赖

1

sudo apt install build-essensial g++

二 解压配置

1
2
3

tar -xf qt-everywhere-src-5.15.2.tar.xz 
cd qt-everywhere-src-5.15.2/
./configure -recheck-all -prefix $PWD/qtbase -opensource -nomake tests

三 处理问题

1. configure帮助

1

./configure --help

2.configure重检查

1

./configure -recheck-all

避免缓存影响，每次安装完新的依赖以后要执行这个参数configure

3. 缺少llvm-config

1
2

sudo apt install libclang-dev clang llvm-dev
sudo ln -s /bin/llvm-config-7 /bin/llvm-config

3. 对Qt Multimedia:GStreamer 1.0添加支持

1

sudo apt install libgstreamer-plugins-base1.0-dev libgstreamer-plugins-base1.0-0 gstreamer1.0-qt5

4. 缺少xkb

1

sudo apt install libxkbcommon-dev

5. 缺少node.js

1

sudo apt install nodejs

6. 缺少fontconfig

1

sudo apt install libfontconfig1-dev

7. 缺少dbus

1

sudo apt install libdbus-1-dev dbus

8. 缺少nss3

1

sudo apt install libnss3-dev

9. 缺少egl

1

sudo apt install libegl1-mesa-dev

10. 其他依赖

1

sudo apt install flex bison gperf
